# 게임 디자인 문서 (GDD)

## 코어 루프

은신처(스태시 정리) → 로드아웃 → 레이드(수색·루팅·교전) → 탈출 성공(소지품 보존) / 사망(소실) → 결과 → 은신처

## 레이드

모바일 세션 길이를 고려한 파라미터.

- 제한시간 15분, 맵 약 300×300 m
- 탈출 지점 3~4개: 상시 2 / 조건부 1~2 (레버 작동, 비용 지불 등). 탈출 대기 7초
- 사망 시 장비 슬롯·배낭·리그 내용물 소실, 보안 컨테이너만 보존
- 탈출 성공 시 소지품을 스태시로 이전. 스태시 공간 부족 시 이전 불가 아이템은 소실 경고 후 처리

## 인벤토리 규격

| 컨테이너 | 크기 | 비고 |
|---|---|---|
| 스태시 | 10×30 (확장 가능) | 레이드 밖에서만 접근 |
| 주머니 | 1×1 ×4 | 항상 존재 |
| 전술 조끼(리그) | 그리드 묶음, 예: 1×2 ×4 | 장착 시 제공 |
| 배낭 | 4×4 ~ 6×7 | 장착 시 제공, 배낭 안 배낭 금지 |
| 보안 컨테이너 | 2×2 | 사망 시 보존 |

장비 슬롯: 주무기 2, 보조무기 1, 헬멧, 방탄복, 리그, 배낭, 보안 컨테이너.

아이템은 직사각형(W×H), 90° 회전 가능 여부는 아이템별. 같은 종류는 최대 스택 수까지 합쳐짐.

## 콘텐츠 확장 원칙: 데이터 주도

아이템·탄약·무기·부착물·약품·장비는 전부 데이터(Godot `Resource`, `.tres` 파일)로 정의한다.

- 새 아이템 추가 = 데이터 추가 (코드 변경 없음)
- 새 *동작*(새 약품 효과 종류, 새 사격 방식)만 코드 추가
- 효과는 `ItemEffect` 리소스 조합형(지혈·회복·진통·버프)이라 약품 추가도 대부분 데이터로 처리

### MVP 아이템 (~40종)

무기 3, 탄창 3~4, 탄약 3종(9mm / 5.56 / 12ga), 부착물 6~8, 의료 4(붕대·구급상자·지혈대·진통제), 가치품 10, 장비 8(헬멧·방탄복·리그·배낭 등급별), 식음료 2.

### MVP 이후 확장 로드맵

| 분류 | MVP | 확장 목표 |
|---|---|---|
| 무기 | 3 (권총·소총·샷건) | 15+ : SMG, DMR, 저격소총, 기관총, 리볼버 등 |
| 탄약 | 3 구경 × 1종 | 구경별 2~4종 (FMJ·AP·HP 등 관통력/데미지 상충) |
| 부착물 | 6~8 | 50+ : 총열·핸드가드·개머리판·손잡이·레이저·라이트 |
| 약품 | 4 | 12+ : 부위 치료·골절 부목·각성제(버프/디버프) |
| 장비 | 8 | 등급별 방탄복·헬멧(바이저·헤드셋)·리그·배낭 다양화 |
| 기타 | 가치품 10, 식음료 2 | 열쇠(잠긴 방), 제작 재료, 퀘스트 아이템 |

무기·장비는 MVP 이후 계속 추가한다 (M13부터, 데이터 추가 방식). 우선 후보:
- 무기: SMG, 카빈, DMR, 볼트액션 저격소총, 경기관총, 리볼버, 펌프·반자동 샷건
- 장비: 방탄복 등급 1~6, 플레이트 캐리어(리그 일체형), 헬멧 + 바이저·헤드셋, 크기별 배낭, 야간투시경

## 아이템 수색 (MVP 포함)

- 루팅 컨테이너(서랍·상자·가방·사망한 적)를 열면 내용물이 **미확인(?)** 상태
- 수색을 진행하면 아이템이 위에서부터 하나씩 공개. 아이템당 수색 시간 = 기본값 × 크기·희귀도 계수 (0.5~3초)
- 이동·피격·사격 시 수색 중단. 진행도는 이미 공개된 아이템까지 유지
- 공개된 아이템만 집을 수 있음. 집는 시간은 별도(대형 아이템일수록 길게)
- 수색 시 소음 발생 → AI 청각 감지와 연동 (위험과 보상의 긴장감)
- 배낭 등 컨테이너형 아이템 내부도 미확인 처리 가능
- 후속: 수색 속도 스킬·장비 보정

## 무기

### MVP 3종

| 무기 | 인벤토리 | 탄 | 부착 소켓 |
|---|---|---|---|
| 권총 | 2×1 | 9mm | 소음기, 조준경(소형) |
| 소총 | 5×2 | 5.56 | 조준경, 소음기, 탄창 |
| 샷건 | 5×2 | 12ga | 조준경 |

탄창은 탄을 담는 컨테이너다. 장전하면 실제 탄 수를 소비한다.

### 총기 모딩 (구조는 처음부터, 콘텐츠는 단계적)

- 무기 = **부품 트리**: 리시버 → 총열·핸드가드·개머리판·탄창 → 핸드가드에 손잡이·레이저 … (부품이 다시 소켓을 가짐)
- 호환성: 소켓 타입 + 허용 목록 + 충돌 규칙 (예: 특정 핸드가드는 특정 손잡이 불가)
- 최종 스탯 = 기본 + 부품 트리 전체 수정치 합산 (반동·인체공학·무게·정확도·소음)
- **인벤토리 크기도 부품에 따라 변함** (긴 총열·접이식 개머리판 → 그리드 폭 변경)
- 3D 외형: 부품마다 메시 + 소켓 → 트리대로 런타임 조립
- MVP는 트리 구조와 소켓 3개 수준만 사용. M12에서 부품 종류 확대 + 전용 모딩 화면(3D 미리보기·스탯 비교)

## 전투·체력 (MVP 단순화)

- 단일 HP + 출혈 상태 1종
- 방탄복 등급 vs 탄 관통력 비교로 피해 감소 결정
- 부위별 체력·골절은 후속

## 적 AI (인간형 무장)

- 상태: 순찰 → 의심(소리·시야) → 교전 → 엄폐 → 수색 → 복귀
- 감지: 시야각·거리·조도 기반 시각, 총성·발소리·수색 소음 청각 전파
- 사망 시 착용 장비가 루팅 가능한 컨테이너(수색 대상)가 됨
- 난이도: 반응시간·명중 분산·인지거리로 조절

- MVP: NPC 상인 1명 (판매 + 기본 장비 구매)
