# M7 탭 검증 체크리스트 (절차적 반동·ADS · 모듈식 무기 외형 · 모딩 화면)

## 확인할 내용 (요약)
- **반동 느낌**: 쏠 때 카메라가 위로 튀고 살짝 좌우로 흔들리는지, 총 모델이 뒤로 밀렸다 부드럽게 돌아오는지. 소총(약함) < 권총 < 샷건(강함) 순으로 체감이 달라지는지. 조작성이 높은 부품(개머리판·손잡이)을 달면 반동이 줄어드는지
- **ADS 속도·줌**: 조준이 약 0.35~0.4초에 끝나는지, 조작성이 낮은 조준경(4배율)을 달면 느려지는지. 시야각(줌)이 레드 도트(약간) < 4배율 조준경(크게)로 달라지고, 4배율에서는 둥근 스코프 화면이 뜨는지
- **흔들림**: 가만히 있을 때 총이 숨 쉬듯 살짝 흔들리고, 걸을 때 위아래로 보빙, 시점을 돌릴 때 총이 살짝 뒤처지는지. 조준 중에는 이 움직임이 크게 줄어드는지 (너무 심하거나 멀미가 나지 않는지)
- **달리기 자세**: 달릴 때 총이 아래·옆으로 눕고, 사격·조준하면 바로 올라오는지. 재장전 중 총이 내려가는지, 무기 교체 시 아래에서 올라오는지
- **총 크기**: 1인칭 총이 화면 오른쪽 아래만 차지하고 시야를 가리지 않는지 (예전엔 상자 하나가 화면의 1/3). 소총·샷건·권총 모양이 구분되는지, 부품(소음기·긴 총열·손잡이·조준경·접이식 개머리판)을 달면 외형이 바뀌는지
- **모딩 화면 흐름**: 가방(Tab/I 또는 HUD `가방` 버튼) → 소총 선택 → `모딩` → 소켓 선택 → 부품 선택 → 장착/분리. 한글이 깨지지 않고 버튼이 엄지로 누르기 편한지
- **스탯 미리보기**: 부품을 한 번 누르면 변화가 초록(좋아짐)/빨강(나빠짐)으로 나오는지. 반동·퍼짐·무게·소음·조준 시간은 낮을수록 좋음 → 줄면 초록
- **인벤토리 크기 변화**: 긴 총열·소음기를 달면 소총이 5×2 → 6×2·7×2로 커지고, 접이식 개머리판은 한 칸 줄어드는지. 옆 칸이 막혀 있으면 "공간 부족" 알림이 뜨고 아무것도 바뀌지 않는지

## 0. 최신 코드 받기
1. **Godot 에디터를 먼저 닫는다**
2. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
3. Godot 에디터를 다시 열고 프로젝트 불러오기 (새 스크립트 임포트에 잠깐 걸림)

## 1. 실행
Play(▶) → 개발 메뉴에서 **Combat Test** (사격장 + 가방) 또는 **Inventory** (스태시가 있는 인벤토리 데모).
- 소총(1번)에는 기본 부품이 달려 있다: 숏 배럴, 레일 핸드가드, 고정 개머리판, 30발 탄창, 레드 도트.
- 여분 부품은 가방(배낭·조끼·주머니)에 들어 있다: 롱 배럴, 수직 손잡이, 접이식 개머리판, 4배율 조준경, 소음기 ×2, 레드 도트.
- 권총: 총구(소음기)·조준경 소켓, 샷건: 조준경 소켓.

## 2. 해 볼 것
1. **반동·킥백 (사격장)**: 소총을 연사해 본다. 카메라 킥과 별개로 총 모델이 뒤로 밀리고 총구가 들렸다 돌아온다. 같은 소총에 `수직 손잡이`·`롱 배럴`을 달고 다시 쏴서 반동이 줄었는지 비교한다.
2. **ADS**: `조준` 버튼. 약 0.4초에 걸쳐 총이 가운데로 오고 시야가 좁아진다. 레드 도트의 조준점(빨간 점)이 화면 가운데에 오는지 본다. `4배율 조준경`으로 바꾸고 다시 조준: 더 느리고(조작성 −7) 시야가 훨씬 좁고 둥근 스코프 화면이 뜬다.
3. **흔들림·보빙**: 가만히 서서 총 흔들림, 걸으면서 보빙, 시점을 빠르게 돌릴 때 뒤처짐, 조준 중에는 거의 사라지는지.
4. **달리기 자세**: 조이스틱을 끝까지 밀어 달린다. 총이 아래로 눕는다. 사격 버튼을 누르면 올라온다 (기존 0.2초 발사 지연 유지). 재장전 중에는 총이 내려갔다 올라온다.
5. **가방 열기**: HUD 오른쪽 위 `가방` 버튼 (키보드는 `Tab` 또는 `I`, 닫기도 같은 키/`Esc`). 열려 있는 동안 플레이어 이동·사격·카메라는 멈춘다.
6. **모딩 열기**: 슬링의 소총을 탭 → 아래 바의 `모딩`. 왼쪽 위에 소총 3D 미리보기(천천히 회전, 끌면 돌아감), 왼쪽 아래 스탯 표, 가운데 소켓 트리, 오른쪽에 부품 목록.
7. **장착**: 가운데에서 `└ 총구: (비어 있음)` 탭 → 오른쪽에서 `소음기` 탭 → 스탯 표에 변화(소음 ×0.40 초록, 무게·사거리 빨강 등)와 `(크기 5×2 → 6×2)`가 뜬다 → `장착` 버튼 또는 같은 부품을 한 번 더 탭.
8. **안 되는 부품**: 같은 소켓에서 `롱 배럴`·`수직 손잡이`는 흐리게 + `종류 불일치`. `접이식 개머리판`을 달고(개머리판을 먼저 분리) 조준경 소켓을 보면 `4배율 조준경`이 `충돌: 접이식 개머리판`으로 막힌다.
9. **분리**: 부품이 달린 소켓을 탭 → `분리` (누르기 전에 스탯 표에 분리 시 변화가 미리 보인다). 아래에 부품이 달린 총열은 `하위 부품을 먼저 분리하세요` (총구의 소음기부터 떼야 함).
10. **필수 부품**: 총열을 떼면 `필수 부품 없음 (총열) · 사격 불가`가 뜨고 사격장에서 쏘면 알림만 나온다.
11. **크기 변화**: 스태시(인벤토리 데모)에서 소총에 소음기·긴 총열을 달면 그리드의 소총이 한 칸씩 늘어난다. 오른쪽이 막혀 있으면 "공간 부족" 알림.
12. **바로 시험**: 모딩을 닫고(`닫기`/`Esc`) 가방도 닫아 사격장에서 반동·ADS 변화를 확인한다.

## 3. 알려 줄 것 (스크린샷 포함)
- 반동 세기·회복 속도, 총구 들림·킥백 크기, ADS 시간과 줌 배율이 적당한지
- 흔들림·보빙이 거슬리거나 멀미 나는지, 달리기·재장전 자세가 어색한지
- 총 위치·크기: 오른쪽 아래 위치, 시야 가림 정도, 벽에 가까이 갔을 때 총이 벽을 뚫는지
- 모딩 화면: 버튼 크기, 목록 스크롤, 두 번 탭 장착이 직관적인지, 미리보기 3D 회전·끌기, 한글 깨짐, 겹침
- 스탯 미리보기의 색·표기, 인벤토리 크기 변화와 "공간 부족" 동작
- 총기를 많이 바꿔 끼운 뒤 프레임이 떨어지거나 모델이 비는지
