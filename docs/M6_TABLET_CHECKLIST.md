# M6 탭 검증 체크리스트 (FPS 컨트롤러 · 터치 컨트롤 · 사격)

## 확인할 내용 (요약)
- 왼쪽 조이스틱이 엄지가 닿는 곳에 뜨고, 이동이 부드러운지 (끝까지 밀면 달리기)
- 오른쪽 드래그 시점 감도가 적당한지 (너무 빠르거나 느린지)
- 사격 버튼을 누르고 있으면 소총이 연사되고, 샷건·권총은 한 번 누를 때 한 발인지
- 조준(ADS) 토글, 재장전(약 2초 / 권총 1.5초), 앉기, 점프, 무기 교체 버튼이 동작하는지
- **멀티터치**: 이동 + 시점 + 사격을 동시에 해도 끊기지 않는지
- 버튼 크기·위치가 엄지로 누르기 편한지, 서로 겹치거나 HUD를 가리지 않는지, 한글이 깨지지 않는지

## 0. 최신 코드 받기
1. **Godot 에디터를 먼저 닫는다**
2. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
3. Godot 에디터를 다시 열고 프로젝트 불러오기 (새 스크립트 임포트에 잠깐 걸림)

## 1. 실행
Play(▶) → 개발 메뉴에서 **Combat Test** 탭. 사격장에 더미 3개(10 m 방탄 없음 / 20 m 방탄 3급 / 35 m 방탄 5급)가 있고, 죽이면 3초 뒤 되살아난다.
HUD: 왼쪽 위 체력, 아래 가운데 `현재 / 용량` + 무기 이름 + 예비 탄약, 화면 중앙 조준선(조준 중엔 숨김).

## 2. 해 볼 것
1. **조이스틱**: 화면 왼쪽 40% 아무 곳이나 누르면 그 자리에 원이 뜬다. 위로 밀면 앞으로, 끝까지 밀면 달리기. 손가락을 떼면 사라지고 멈춘다.
2. **시점 드래그**: 오른쪽(버튼 아닌 곳)을 누른 채 움직인다. 위아래는 ±85°에서 멈춰야 한다.
3. **사격(누르고 있기)**: 소총(1번)으로 10 m 더미를 쏜다. 연사되고, 맞으면 더미 위 HP가 줄고 조준선에 X 표시. 사격 버튼을 누른 채 드래그해도 시점이 움직인다.
4. **무기 교체**: `무기` 버튼으로 소총 → 샷건 → 권총. 샷건은 한 번 누를 때 산탄 8발, 권총·샷건은 누르고 있어도 한 발씩.
5. **조준(ADS)**: `조준`을 누르면 시야가 좁아지고 조준선이 숨는다. 다시 누르면 해제. 조준 중엔 퍼짐·시점 속도가 줄어든다.
6. **재장전**: 몇 발 쏜 뒤 `재장전`. 약 2초 동안 진행 막대가 차고 그동안은 못 쏜다. 탄창이 가득이면 "탄창 가득 참", 예비 탄이 없으면 "탄약 없음" 알림.
7. **앉기 / 점프**: `앉기`는 토글(시점이 낮아지고 느려짐), `점프`는 앉은 상태에서 누르면 먼저 일어선다. 오른쪽 경사로와 단상에 올라가 본다.
8. **방탄 확인**: 20 m(3급)·35 m(5급) 더미는 소총탄이 막히는 일이 있다 (막히면 피해가 적고 X 표시가 회색).
9. **멀티터치**: 왼손으로 조이스틱, 오른손 엄지로 사격 버튼을 누른 채 드래그(또는 다른 손가락으로 시점 드래그)를 동시에.
10. **마우스/키보드 연결 시** (선택): WASD, Shift, Ctrl/C, Space, 마우스, R, 1/2/3, Q. 마우스를 쓰면 터치 버튼이 숨고 화면을 다시 터치하면 나타난다.

## 3. 알려 줄 것 (스크린샷 포함)
- 시점 감도 (너무 빠름/느림, ADS 중 감도), 조이스틱 반지름·데드존·달리기 진입 쉬움
- 버튼 크기(최소 64 px)·위치: 엄지가 안 닿거나 서로 겹치는 버튼, HUD 탄약 칸을 가리는지
- 사격 반응(눌렀을 때 지연), 연사 중 프레임, 재장전 시간이 길거나 짧은지
- 멀티터치에서 입력이 씹히거나 엉뚱한 역할로 먹히는 경우 (예: 조이스틱 중 시점이 안 움직임)
- 한글 깨짐, HUD 글자 크기, 조준선 모양·위치, 임시 총 모델이 시야를 가리는지
