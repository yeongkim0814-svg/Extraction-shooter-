# M5 탭 검증 체크리스트 (인벤토리 UI)

## 0. 최신 코드 받기
1. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
2. Godot 에디터에서 프로젝트 다시 불러오기 (폰트 임포트에 잠깐 걸릴 수 있음)

## 1. 실행
Play(▶) → 개발 메뉴에서 **Inventory Demo** 탭. 한글이 네모(□)로 보이면 바로 스크린샷.

## 2. 해 볼 것
1. **롱프레스 드래그**: 스태시의 권총을 꾹 눌렀다가(약 0.25초) 끌어서 빈 칸에 놓기. 초록=가능, 빨강=불가.
2. **회전**: 소총(5×2)을 끄는 동안 다른 손가락으로 화면 아무 곳이나 탭, 또는 "회전" 버튼. 세로로 돌아가는지.
3. **탄약 합치기**: 9mm 탄 두 더미를 겹쳐 놓기 (한쪽이 60 넘으면 남는 수량 확인).
4. **장착/해제**: 권총을 왼쪽 "보조무기" 슬롯으로, 헬멧을 "주무기" 슬롯으로(거부되어야 함), 장착한 것을 다시 스태시로.
5. **탭 정보 + 나누기**: 탄약을 짧게 탭 → 정보 창 → "반으로 나누기".
6. **스크롤**: 스태시를 빈 곳에서 손가락으로 밀어 스크롤. 드래그 중 위/아래 끝에 가져가면 자동 스크롤.
7. **취소**: 끄는 도중 표 바깥(장비·스태시 밖의 빈 곳)에 놓으면 제자리.

## 3. 알려 줄 것 (스크린샷 포함)
- 터치 칸 크기(48)가 작거나 큰지
- 롱프레스 시간(0.25초)이 짧거나 긴지, 스크롤하려다 집어지거나 집으려다 스크롤되는지
- 드래그 중 두 번째 손가락 회전이 되는지, 안 되면 "회전" 버튼은 누르기 쉬운지
- 글자 깨짐·겹침·잘림, 에러 문구(빨간 글씨)
