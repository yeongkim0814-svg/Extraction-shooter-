# M5 탭 검증 체크리스트 (인벤토리 UI)

## 0. 최신 코드 받기
1. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
2. Godot 에디터에서 프로젝트 다시 불러오기 (폰트 임포트에 잠깐 걸릴 수 있음)

## 1. 실행
Play(▶) → 개발 메뉴에서 **Inventory Demo** 탭. 한글이 네모(□)로 보이면 바로 스크린샷.

화면은 반반: **왼쪽 = 장비 슬롯 페이지**(머리·귀·방탄복·얼굴·눈 / 슬링+권총집 / 등+칼집 / 주머니 / 조끼·가방·보안), **오른쪽 = 스태시**. 둘 다 세로 스크롤.
롱프레스는 없다.

## 2. 해 볼 것
1. **즉시 드래그**: 스태시의 권총을 누른 채 조금(약 10px) 움직이면 바로 집힌다. 초록=놓을 수 있음, 빨강=불가. 손가락을 떼면 실행.
2. **스크롤**: 아이템이 없는 빈 곳(칸 사이 빈 칸, 슬롯 페이지 오른쪽 빈 공간 포함)을 누른 채 위아래로 밀기. 왼쪽/오른쪽 각각 따로 스크롤되고, 아이템이 끌리면 안 된다.
3. **탭 = 선택**: 아이템을 짧게 탭하면 노란 윤곽선이 생기고 아래에 액션 바(회전 / 정보 / 나누기 / 장착·해제 / 버리기)가 뜬다. 선택한 아이템이 액션 바에 가려지지 않는지.
4. **탭으로 이동**: 선택한 채 스태시나 컨테이너의 빈 곳을 탭하면 가장 가까운 자리로 이동. 자리가 없으면 그 자리가 빨갛게 번쩍이고 선택은 유지(알림 문구 표시).
5. **합치기**: 탄약 선택 후 같은 종류 탄약 더미를 탭 (가득 차면 합쳐지지 않음).
6. **장착 / 해제**: 안경을 선택 → "장착"(눈 슬롯). 방탄복(슬롯에 장착됨)을 선택 → "해제"(스태시로). 선택한 채 빈 슬롯 박스를 탭해도 장착, 호환 안 되는 슬롯은 빨간 번쩍임.
7. **회전**: 소총 선택 → "회전". 제자리에 들어가면 바로 돌고, 안 들어가면 알림만 뜨고 다음 이동에 적용(액션 바의 칸 모양 미리보기가 가로↔세로로 바뀜). 드래그 중엔 다른 손가락 탭으로 회전.
8. **나누기**: 탄약(수량 2 이상) 선택 → "나누기"(반으로).
9. **정보 / 버리기**: "정보"는 이름·크기·수량 창, "버리기"는 확인 창(취소 / 버리기)이 뜨는지.
10. **선택 해제**: 선택한 아이템을 다시 탭, 그리드 밖 빈 곳 탭.
11. **드래그 + 선택 공존**: 선택한 상태에서 다른(또는 같은) 아이템을 끌면 액션 바가 사라지고 드래그, 놓으면 실행.
12. **드래그 자동 스크롤**: 드래그 중 스태시/슬롯 페이지 위·아래 끝에 가져가면 그 쪽이 자동 스크롤.
13. **취소**: 끄는 도중 슬롯·그리드 밖에 놓으면 제자리.

## 3. 알려 줄 것 (스크린샷 포함)
- 칸 크기(스태시 10열이 반쪽 폭에 맞춰 40~56 사이로 정해짐)가 작거나 큰지
- 빈 곳 스크롤 vs 아이템 드래그가 의도대로 갈리는지 (스크롤하려다 집어지거나, 집으려다 스크롤됨)
- 탭이 가끔 드래그로 먹히거나, 반대로 드래그가 탭으로 먹히는지 (약 10px 기준이 짧거나 긴지)
- 액션 바 버튼(최소 높이 52px) 크기·글자 대비, 한쪽 손으로 누르기 편한지
- 왼쪽 슬롯 페이지 배치(스케치와 다른 점), 글자 깨짐·겹침·잘림, 에러 문구
- 두 번째 손가락 회전이 되는지
