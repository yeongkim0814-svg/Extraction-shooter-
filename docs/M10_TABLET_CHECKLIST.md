# M10 탭 검증 체크리스트 (그래픽 패스: 흐린 산업단지)

## 확인할 내용 (요약)
- **fps**: 단계별(LOW/MID/HIGH) 레이드 프레임. 목표 60 fps
- **무드**: 콘셉트 보드(docs/art/industrial_mood.webp)와 비교
- **적 가독성**: 어두운 공장 실내에서 올리브 캡슐이 보이는지
- **웅덩이 반사 · 연기 · 그림자 계단 현상**
- **발열·배터리**: 10분 플레이 뒤

## 0. 최신 코드 받기
1. Godot 에디터를 먼저 닫는다
2. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
3. 에디터를 다시 열고 프로젝트 불러오기 (새 리소스 임포트에 시간이 걸린다)

## 1. 시작
Play(▶) → 개발 메뉴 → **레이드 (산업단지)**. 기본 품질은 안드로이드 MID. 시작할 때 `RAID: quality MID` 로그가 나온다.
- 개발 키: V = 시점 순간이동(공장·실내·마당·창고·철길), F2 또는 네 손가락 터치 = 품질 순환.

## 2. fps (단계별)
각 단계에서 정문 → 마당 → 공장 홀 안으로 이동하며 1분씩 본다. 로그 `RAID: render draw_calls=... fps=...`(5초마다)를 같이 적는다.
| 단계 | 평균 fps | 최저 fps | draw_calls |
|---|---|---|---|
| LOW | | | |
| MID | | | |
| HIGH | | | |
- 합격: MID에서 60 fps 근처, draw_calls 약 150 이하. 적 6명이 모두 보이는 마당에서도 유지.
- 단계를 바꿀 때 멈춤이 크지 않은지.

## 3. 무드 (콘셉트 보드 비교)
V 키로 공장·실내·마당 시점을 보고 보드와 비교한다.
- 흐린 회청색 하늘, 낮은 태양 글로우가 보이는가
- 전체가 어둡고 차갑고 채도가 낮은가, 녹·주황 포인트가 소량 있는가
- "03" 공장 건물과 굴뚝(일부 연기), 타워크레인, 철탑이 보이는가
- 쌓인 컨테이너, 버려진 트럭, 파이프 랙이 보이는가
- 젖은 아스팔트, 웅덩이, 잡초가 보이는가
- 안개가 너무 하얗거나 너무 짙지 않은가 (조정 상수는 아래 6장)

## 4. 어두운 실내 적 가독성
- 공장 홀·창고 안에서 올리브색 적이 배경과 구분되는가 (약한 발광 + 림). 너무 번쩍이지는 않은가
- 창문 빛 기둥과 램프가 분위기를 만들되 시야를 가리지 않는가
- 밝은 창 쪽을 볼 때 눈부심(글로우)이 과한가

## 5. 반사·연기·그림자·발열
- **웅덩이 반사**: 웅덩이가 하늘/건물을 어색하지 않게 비추는가, 걸을 때 깜빡이지 않는가
- **연기**: 굴뚝 연기가 자연스러운가, 단계 LOW에서도 보이는가, 프레임이 떨어지지 않는가
- **그림자 계단 현상**: MID(1분할 30 m)·HIGH(2분할 45 m)에서 그림자 가장자리 계단·깜빡임, 분할 경계가 눈에 띄는지
- **10분 발열·배터리**: 10분 연속 플레이 뒤 기기 온도, 배터리 감소량(%), 그 사이 fps 저하 여부

## 6. 조정할 상수 (실기기 결과에 따라)
- `assets/env/industrial_env.tres`: `tonemap_exposure`(0.96), `adjustment_contrast`(1.12), `adjustment_saturation`(0.78), `fog_density`(0.0034), `fog_light_energy`(0.85), `fog_light_color`, `ambient_light_energy`(0.68), `glow_intensity`(0.5)
- `scripts/core/graphics/graphics_tier.gd`: 단계별 렌더 배율·그림자 거리·파티클 비율·잡초 밀도
- `scripts/game/ai/enemy_agent.gd`: `ALIVE_GLOW_ENERGY`(0.4), 림 값
- `scenes/raid/industrial.tscn`: 태양 `light_energy`(1.5), `shadow_bias`, `shadow_blur`
