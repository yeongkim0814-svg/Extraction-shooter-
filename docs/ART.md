# 그래픽·모델링·에셋 가이드

## 1. 그래픽 디렉션: 세미리얼, 전환 가능

**전환 가능 구조 (핵심 원칙):** 씬의 모든 머티리얼은 소수의 프로젝트 마스터 셰이더(`.gdshader`)에서 파생한 `ShaderMaterial`이다. M10에서 스타일라이즈드로 전환하기로 하면 마스터 셰이더·컬러 보정·텍스처 세트만 교체하고 씬은 재작업하지 않는다.

| 마스터 셰이더 | 용도 |
|---|---|
| `master_opaque.gdshader` | 환경·소품·캐릭터 일반 |
| `master_foliage.gdshader` | 식생 (바람, 알파 컷) |
| `master_decal` (Decal 노드 + 텍스처 규칙) | 오염·균열·표식 |
| `weapon_fp.gdshader` | 1인칭 무기 (별도 FOV, 벽 관통 방지) |

마스터 셰이더는 Mobile·Compatibility 두 렌더러에서 모두 컴파일되는 기능만 쓴다.

### 렌더러별 그래픽 범위

| | Android (Mobile 렌더러) | 웹 (Compatibility 렌더러) |
|---|---|---|
| PBR 머티리얼 | 지원 | 지원 |
| 실시간 그림자 | 방향광 1개 | 방향광 1개 (저해상도) |
| 글로벌 일루미네이션 | 라이트맵(LightmapGI) | 라이트맵 |
| 화면 공간 효과(SSAO 등) | 제한적 | 없음 → AO는 텍스처에 베이크 |
| 후처리 | 톤매핑·컬러 보정·글로우 | 톤매핑·컬러 보정 위주 |

세부 지원 범위는 M4에서 두 플랫폼 실측으로 확정한다. **웹의 세미리얼 표현은 지오메트리·라이팅보다 PBR 텍스처 품질과 베이크된 AO·라이트맵에 의존**한다.

### 라이팅

- 주력: 라이트맵(LightmapGI) + 리플렉션 프로브, 실시간 방향광 1개
- **라이트맵 베이크는 GPU 렌더러가 필요** → 탭 에디터에서 가능한지 M4에서 확인. 불가하면 PC 세션에 맵 단위로 몰아서 베이크
- 안개: 분위기 + 원거리 시야 제한 겸용. 실내외 경계는 오클루더(OccluderInstance3D)로 컬링

### 품질 티어 (설정에서 선택, 기기 자동 판별)

| 티어 | 대상 | 렌더 스케일 | 그림자 | 후처리 | 텍스처 |
|---|---|---|---|---|---|
| Low | 저가 폰·모바일 웹 | 0.7 | 끔 | 톤매핑만 | 512~1K |
| Mid | 중급 폰·태블릿 | 0.85 | 저해상도 | +컬러 보정 | 1K |
| High | 고급 폰·데스크톱 웹 | 1.0 | 기본 | 전체 | 1~2K |

**목표 프레임:** 중급 안드로이드 30fps 고정, 고급 기기·데스크톱 웹 60fps.

## 2. 폴리곤·텍스처 예산

| 에셋 | 트라이 | 텍스처 | LOD |
|---|---|---|---|
| 1인칭 무기 (부품 합계) | 6~10k | 2K (1세트) | 없음 |
| 월드 드롭 무기 | ≤2k | 1인칭 텍스처 공유 | 자동 LOD |
| 1인칭 팔 | 5~8k | 1K | 없음 |
| 적 캐릭터 | 10~15k | 2K 아틀라스 | 자동 LOD |
| 모듈 환경 조각 | 200~2k | 타일·트림 텍스처 공유 | 자동 LOD |
| 소품 | 100~1.5k | 아틀라스 | 자동 LOD |

Godot은 임포트 시 메시 LOD를 자동 생성한다 (수동 LOD 제작 불필요).
화면 전체 상한: 트라이 ≤300k, 드로우콜 ≤150(모바일), 텍스처 메모리 ≤500MB (웹 ≤300MB).

## 3. 모델링 도구와 역할

| 도구 | 기기 | 담당 |
|---|---|---|
| **Nomad Sculpt** | 갤럭시 탭 (S펜) | 무기 부품, 소품, 캐릭터 스컬프트, 버텍스/PBR 페인팅 |
| **Godot 에디터** | 갤럭시 탭 | 모델 조립, 소켓(Marker3D) 지정, 머티리얼, 레벨 그레이박스(CSG) |
| **Mixamo** (웹) | 탭 브라우저 (데스크톱 모드, 동작 확인 필요) 또는 PC | 캐릭터 자동 리깅·애니메이션 |
| **Blender** (선택) | PC 세션 | Nomad로 부족할 때만: 리토폴로지·UV·노멀맵 베이크·정밀 하드서피스 |
| CC0 에셋 | — | 텍스처·HDRI·플레이스홀더 모델 |

### Nomad Sculpt로 게임 무기 만드는 흐름

1. 기본 도형(박스·실린더)으로 부품 형태 잡기 → 불리언·트림으로 각진 면 만들기
2. (필요하면) 디테일 스컬프트
3. 데시메이트 / 리메시로 트라이 예산까지 줄이기
4. 자동 UV → PBR 페인팅 (색·거칠기·금속성)
5. **glTF(.glb)로 내보내기** → Godot으로 임포트

한계와 대응:
- 스컬프트 도구라 정밀한 기계 디테일·깔끔한 엣지 흐름에 약함 → **부품을 작게 나눠 모델링** (모딩 부품 트리와 자연히 맞음), 세부는 지오메트리 대신 텍스처로 표현
- 소켓용 빈 오브젝트를 만들 수 없음 → 소켓은 Godot에서 부품 씬에 `Marker3D`로 추가
- 리깅 기능 없음 → 캐릭터는 Mixamo
- 결과 품질이 목표에 못 미치는 부품만 PC 세션에서 Blender로 교체

## 4. 무기 모델 사양 (코드와의 계약)

- 단위 m, Y-up, 총구 방향 −Z (Godot 전방 규약), 원점 = 그립 중심 (부품은 장착 소켓 기준)
- 형식: glTF 2.0 (`.glb`). 부품 1개 = 파일 1개 = 상속 씬 1개
- 소켓 (부품 씬의 `Marker3D` 이름):
  - `SOCKET_Muzzle`, `SOCKET_Optic`, `SOCKET_Magazine`, `SOCKET_Ejection`, `SOCKET_Barrel`, `SOCKET_Handguard`, `SOCKET_Stock`, `SOCKET_Grip`
  - `SOCKET_LeftHand` (왼손 IK 대상)
- 움직이는 부품은 분리 메시: 슬라이드/볼트, 탄창, 방아쇠
- 애니메이션: 재장전(tactical/empty)·장착은 키프레임 또는 코드 트윈, **반동·흔들림·ADS는 코드 절차적**
- 아이콘: `SubViewport`로 자동 렌더 (셀당 64px, 회전 아이콘 포함). 부품 구성이 바뀌면 재생성

## 5. 환경: 버려진 산업단지

### 모듈 키트 (4m 그리드 스냅)

- 벽 4×4, 바닥 4×4, 문 개구부 2×2.5, 계단, 철골 기둥, 지붕 트러스
- 대형 구조: 창고, 사무동, 컨테이너 야적장, 탱크·파이프 구역, 경비초소
- 대부분 단순 형태라 **스컬프트 불필요**: 기본 도형 + CC0 PBR 텍스처(콘크리트·녹슨 금속·골강판·아스팔트) + 오염 데칼로 세미리얼 질감 확보
- 루팅 컨테이너 소품(서랍장·공구함·나무 상자·군용 상자·캐비닛·더플백)은 Nomad Sculpt

### 레벨 디자인 순서

1. 그레이박스: Godot **CSG 노드**로 탭에서 동선·교전 거리·탈출 지점 배치
2. 플레이테스트 (AI·수색·탈출 루프)
3. 모듈 메시로 교체 → 라이트맵 베이크

## 6. 캐릭터·애니메이션

- 휴머노이드: Nomad Sculpt 모델 → Mixamo 자동 리깅 → Godot 임포트(FBX 기본 지원), 리타기팅으로 애니메이션 공유
- 조준 방향 보정: `SkeletonIK3D` / 본 회전 코드
- 1인칭 팔: 별도 메시, 무기별 그립 포즈

## 7. 에셋 조달 규칙

1. 라이선스 명확한 외부 소스: Poly Haven·ambientCG (CC0), Godot Asset Library, Mixamo
2. Higgsfield: `generate_image`로 콘셉트 아트·Nomad 작업용 참고 이미지, `generate_3d`로 블록아웃(최종 품질 아님)
3. Nomad Sculpt 직접 제작 → 부족한 부분만 Blender

- 모든 외부 에셋은 [ASSET_LICENSES.md](ASSET_LICENSES.md)에 출처·라이선스 기록
- 바이너리(glb·png·wav·ogg 등)는 **Git LFS**로 관리

## 8. 오디오

- 총성 거리 레이어 (근·중·원), 실내/실외 변형
- 표면별 발소리 (콘크리트·금속·자갈·풀)
- 실내 리버브: `Area3D` 오디오 버스 오버라이드
- 오디오 버스: SFX / 무기 / 환경 / UI / 음악
- 모바일 동시 재생 수 제한 (`AudioStreamPlayer3D.max_polyphony` + 거리 컬링)

## 9. UI/UX (터치 우선)

- 가로 모드 고정. HUD 최소화 (탄약·체력·나침반)
- 터치 컨트롤: 왼쪽 가상 조이스틱, 오른쪽 드래그 조준, 사격·조준·재장전·앉기·점프 버튼, 선택적 자이로 조준, 조준 보정
- 인벤토리 화면: 왼쪽 장비 슬롯, 오른쪽 그리드. 셀 최소 터치 크기 44dp (폰은 스크롤, 태블릿은 넓게)
- 조작: 롱프레스로 집기 → 드래그, 탭은 정보, 회전은 화면 버튼 / 두 손가락 탭. PC 웹은 마우스 + R키
- 수색 UI: 미확인 칸은 `?` 표시, 공개 중인 아이템에 진행 원형 표시
