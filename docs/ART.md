# 그래픽·모델링·에셋 가이드

## 1. 그래픽 디렉션: 세미리얼, 전환 가능

**전환 가능 구조 (핵심 원칙):** 씬의 모든 머티리얼은 소수의 프로젝트 마스터 셰이더(Shader Graph)에서 파생한다. M10에서 스타일라이즈드로 전환하기로 하면 마스터 셰이더·컬러 LUT·텍스처 세트만 교체하고 씬·프리팹은 재작업하지 않는다.

| 마스터 셰이더 | 용도 |
|---|---|
| `SG_Master_Opaque` | 환경·소품·캐릭터 일반 |
| `SG_Master_Foliage` | 식생 (바람, 알파 컷) |
| `SG_Master_Decal` | 오염·균열·표식 |
| `SG_Weapon_FP` | 1인칭 무기 (별도 FOV 렌더, 벽 관통 방지) |

### 라이팅 (모바일·웹 기준)

- 주력: 베이크드 라이트맵 + 라이트 프로브 + 베이크 리플렉션 프로브
- 실시간: 방향광 1개, 그림자 캐스케이드 1~2, 짧은 거리
- AO는 텍스처·라이트맵에 베이크 (SSAO는 고사양 옵션만)
- 포스트: ACES 톤매핑, 컬러그레이딩 LUT, 약한 블룸, 비네팅. 저사양은 최소화
- 안개: 분위기 + 원거리 컬링 겸용. 오클루전 컬링 베이크

### 품질 티어 (설정에서 선택, 기기 자동 판별)

| 티어 | 대상 | 렌더 스케일 | 그림자 | 포스트 | 텍스처 |
|---|---|---|---|---|---|
| Low | 저가 폰·모바일 웹 | 0.7 | 끔 | 톤매핑만 | 512~1K |
| Mid | 중급 폰·태블릿 | 0.85 | 1 캐스케이드 | +LUT | 1K |
| High | 고급 폰·데스크톱 웹 | 1.0 | 2 캐스케이드 | 전체 | 1~2K |

**목표 프레임:** 중급 안드로이드(Galaxy A5x급) 30fps 고정, 고급 기기 60fps, 데스크톱 웹 60fps.

## 2. 폴리곤·텍스처 예산

| 에셋 | 트라이 | 텍스처 | LOD |
|---|---|---|---|
| 1인칭 무기 | 6~10k | 2K (1세트) | 없음 |
| 월드 드롭 무기 | ≤2k | 1인칭 텍스처 공유(밉) | 2단계 |
| 1인칭 팔 | 5~8k | 1K | 없음 |
| 적 캐릭터 | 10~15k | 2K 아틀라스 | 3단계 |
| 모듈 환경 조각 | 200~2k | 트림시트·타일 공유 | 2~3단계 |
| 소품 | 100~1.5k | 아틀라스 | 1~2단계 |

화면 전체 상한: 트라이 ≤300k, 드로우콜 ≤150(모바일), 텍스처 메모리 ≤500MB (웹 ≤300MB).

## 3. 무기 모델 사양 (코드와의 계약)

- 단위 m, Y-up, 총구 방향 +Z, 원점 = 그립 중심
- 소켓은 빈 오브젝트로 명명:
  - `SOCKET_Muzzle`, `SOCKET_Optic`, `SOCKET_Magazine`, `SOCKET_Ejection`
  - `SOCKET_LeftHand` (왼손 IK 대상)
- 움직이는 부품은 분리 메시: 슬라이드/볼트, 탄창, 방아쇠, 해머
- **모딩 대응:** 무기는 부품별 개별 모델(리시버·총열·핸드가드·개머리판 …)로 제작하고, 각 부품도 자식 부품용 `SOCKET_*`를 가진다. 런타임에 부품 트리대로 조립
- 애니메이션: idle, fire, reload(tactical / empty), equip, holster, ADS in/out, sprint, inspect
- 반동·흔들림(sway)·ADS 전환은 **코드 절차적** 처리 → 키프레임 제작은 재장전·장착 위주
- 아이콘: Unity 카메라로 RenderTexture 자동 렌더 (셀당 64px, 회전 아이콘 포함). 부품 구성이 바뀌면 아이콘 재생성
- 내보내기: FBX

## 4. 환경: 버려진 산업단지

### 모듈 키트 (4m 그리드 스냅)

- 벽 4×4, 바닥 4×4, 문 개구부 2×2.5, 계단, 철골 기둥, 지붕 트러스
- 대형 구조: 창고, 사무동, 컨테이너 야적장, 탱크·파이프 구역, 경비초소
- 재질: 콘크리트·녹슨 금속·골강판·아스팔트 타일 텍스처 + 트림시트 + 오염 데칼
- 루팅 컨테이너 소품: 서랍장, 공구함, 나무 상자, 군용 상자, 서류 캐비닛, 더플백

### 레벨 디자인 순서

1. 그레이박스 (ProBuilder) — 동선·교전 거리·탈출 지점 배치
2. 플레이테스트 (AI·수색·탈출 루프 확인)
3. 모듈 아트로 교체 → 라이트 베이크

## 5. 캐릭터·애니메이션

- 휴머노이드 리그 (Mixamo 호환)
- 적 애니메이션: Mixamo 기반 + Animation Rigging으로 조준 방향 보정
- 1인칭 팔: 별도 리그, 무기별 그립 포즈

## 6. 에셋 조달 경로 (우선순위)

1. **라이선스 명확한 외부 소스**: Poly Haven·ambientCG (CC0 텍스처·HDRI·모델), Unity Asset Store 무료 팩, Mixamo
2. **Higgsfield**: `generate_image`로 콘셉트 아트, `generate_3d`로 블록아웃 (최종 품질 아님)
3. **Blender 수작업**으로 최종 교체

규칙:
- 모든 외부 에셋은 [ASSET_LICENSES.md](ASSET_LICENSES.md)에 출처·라이선스 기록
- 바이너리(fbx·png·tga·psd·wav·ogg 등)는 **Git LFS**로 관리

## 8. UI/UX (터치 우선)

- 가로 모드 고정. HUD 최소화 (탄약·체력·나침반)
- 터치 컨트롤: 왼쪽 가상 조이스틱, 오른쪽 드래그 조준, 사격·조준·재장전·앉기·점프 버튼, 선택적 자이로 조준, 조준 보정
- 인벤토리 화면: 왼쪽 장비 슬롯, 오른쪽 그리드. 셀 최소 터치 크기 44pt (폰은 스크롤, 태블릿은 넓게)
- 조작: 롱프레스로 집기 → 드래그, 탭은 정보, 회전은 화면 버튼 / 두 손가락 탭. PC 웹은 마우스 + R키
- 수색 UI: 미확인 칸은 `?` 표시, 공개 중인 아이템에 진행 원형 표시
