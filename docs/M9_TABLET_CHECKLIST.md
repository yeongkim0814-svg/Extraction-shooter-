# M9 탭 검증 체크리스트 (산업단지 레이드 · 수색 · 탈출)

## 확인할 내용 (요약)
- **성능**: 산업단지(약 160 x 160 m)에서 프레임이 부드러운지. 창고 안·야적장·탱크 구역·사무동 2층에서 특히 떨어지지 않는지
- **수색**: 컨테이너를 열면 바로 수색이 시작되고, 아이템이 `?`로 보이다가 위에서부터 하나씩 공개되는지. 진행 중인 칸에 차오르는 채움과 고리가 보이는지
- **중단**: `중단` 버튼으로 멈추고 `수색`으로 이어서 하는지(공개된 아이템은 유지, 진행 중이던 칸만 처음부터). 사격·피격 시 "수색 중단"이 뜨는지
- **소음**: 수색 중에는 약 8 m 안의 적이 의심 상태가 되어 오는지 (0.5초마다 한 번)
- **탈출·결과**: 정문·하수구 탈출 7초, 화물 엘리베이터는 전원 레버 후에만 되는지. 결과 화면의 숫자와 버튼

## 0. 최신 코드 받기
1. **Godot 에디터를 먼저 닫는다**
2. Termux → `cd /storage/emulated/0/Extraction-shooter-` → `git pull`
3. Godot 에디터를 다시 열고 프로젝트 불러오기 (새 스크립트 임포트에 잠깐 걸림)

## 1. 시작
Play(▶) → 개발 메뉴 → **레이드 (산업단지)**. 맵이 만들어지고 내비메시를 굽느라 시작에 1~3초 걸릴 수 있다.
- 플레이어는 맵 남쪽 가장자리에서 북쪽을 보고 시작한다. 구성은 전투 테스트와 같다 (소총·샷건·권총, 예비 탄약, 모딩 부품).
- 화면 위 가운데에 남은 시간(15:00부터 줄어듦)과 탈출 지점 목록 "정문 · 하수구 · 화물 엘리베이터(전원 필요)"가 있다.
- 적은 6명: 정문 초소·창고·탱크 구역·야적장·사무동 1층·2층에 각 1명이 순찰한다.

## 2. 컨테이너 찾기
- 상자 21개: 나무 상자 4x3, 공구함 3x2, 서랍장 4x2, 무기 상자 5x3(경비초소·창고), 의료 가방 3x3(사무동). 6 m 안에 가면 머리 위에 이름이 보인다.
- 2.5 m 안에서 바라보면 오른쪽에 `열기` 버튼이 뜬다(키보드 F).

## 3. 수색
1. `열기`를 누르면 가방 화면 오른쪽에 상자가 열리고 수색이 자동으로 시작된다. 헤더 버튼이 `중단`으로 바뀐다.
2. 공개 전 아이템은 어두운 칸에 `?`만 보인다. 누르거나 끌면 "수색해야 볼 수 있습니다"만 뜨고 아무 일도 없다.
3. 공개된 아이템은 평소처럼 탭 선택 또는 끌어서 내 가방으로 옮긴다.
4. `중단`을 누르면 멈추고 `수색`이 된다. 다시 누르면 이어서 한다. 다 끝나면 `수색 완료`(눌러도 반응 없음).
5. 가방을 닫으면 수색도 멈춘다. 다시 열면 이미 공개된 것은 그대로, 이어서 수색한다.
6. 수색 중 총을 맞으면(가방이 열려 있어도 적은 쏜다) "수색 중단" 알림과 함께 멈춘다.

## 4. 전원 레버 · 화물 엘리베이터
- 사무동 2층(동쪽 바깥 경사로로 올라가 문으로 들어간다)의 북서쪽 방 벽에 **전원 레버**가 있다. 가까이서 `작동`(F) → "전원이 켜졌습니다". 목록의 "(전원 필요)"가 사라지고 서쪽 승강장의 엘리베이터 기둥이 초록색이 된다.
- 전원 전에는 엘리베이터 기둥이 빨강이고 안에 서 있어도 카운트가 되지 않는다.

## 5. 탈출 · 사망 · 결과
- 탈출 지점: 정문(북쪽 끝, 경비초소 앞), 하수구(동쪽 끝), 화물 엘리베이터(서쪽, 전원 필요). 기둥 안에서 **7초** 버티면 탈출. 안에 있는 동안 "탈출 중 n초"와 진행 바가 보이고, 나가면 처음부터.
- 사망(체력 0) 또는 15분 경과(시간 초과)도 같은 결과 화면으로 간다.
- 결과 화면: 제목(탈출 성공 초록 / 사망·시간 초과 빨강), 레이드 시간, 처치한 적, 수색한 컨테이너, 반출한 FIR 아이템 가치(사망·시간 초과면 "잃은 아이템 n개"). `다시 출격`은 레이드를 처음부터, `메뉴로`는 개발 메뉴로. 은신처 저장은 M11에서 연결되므로 지금은 기록이 남지 않는다.

## 6. 개발 키 (데스크톱 전용)
`K` 가까운 적 처치 · `T` 다음 탈출 지점으로 이동 · `G` 가장 가까운 안 연 상자 앞으로 이동 · `P` 전원 켜기 · `F` 열기/작동.

## 7. 알려 줄 것 (스크린샷 포함)
- 프레임 (맵 전체가 보이는 야적장 위쪽, 창고 안, 총을 쏠 때)과 시작 로딩 시간
- 수색 시간이 길거나 짧게 느껴지는지 (아이템당 0.5~3초, 비싼 아이템일수록 오래 걸림)
- 수색 버튼·`?` 칸·진행 고리의 크기와 한글 표시, 오른쪽 위 `닫기` 버튼과의 거리
- 적이 벽·컨테이너에 끼이거나 2층으로 못 올라가는지, 탈출 기둥·상자 이름의 가독성
- 결과 화면 숫자와 버튼 크기
